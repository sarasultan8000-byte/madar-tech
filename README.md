# Madar Tech Landing Page

## About the Project

Madar Tech is an educational and training institution in Khan Younis. This project is a responsive Arabic landing page that introduces the institution, its services, training programs, and contact information.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5 RTL
- JavaScript

## Project Sections

- Home
- About Us
- Services
- Training Programs
- Why Madar Tech
- Contact Us

## Features

- Arabic language and RTL layout
- Responsive design for different screen sizes
- Mobile navigation menu
- Contact form connected to WhatsApp

## How to Run

Open "index.html" in a web browser.
